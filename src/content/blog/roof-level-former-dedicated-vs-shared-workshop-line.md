Choose a dedicated roof-level former when site work overlaps committed workshop orders or the proposed equipment has no documented transfer arrangement. Share one forming line only when the complete workshop-to-site-to-workshop absence fits the order book and the suppliers have defined both installations and their acceptance checks. Count the return to accepted workshop production as the end of each site assignment.

This decision concerns ownership of the forming machine itself. It begins after you have selected both workshop and roof-level production as business activities. The question is whether one identified former can serve both installations or whether the business needs a separate machine for each. The [factory versus mobile-production guide](/blog/fixed-roof-panel-factory-line-vs-mobile-site-production/) addresses the earlier choice of where to produce panels.

## Sharing requires two defined installations

A workshop former has an entry system, supporting arrangement, electrical and control interfaces, cutting equipment and a receiving route. A roof-level arrangement adds an engineered relationship to a lift and the building's panel path. Treat those as two defined configurations of the proposed equipment, not as one machine placed on two convenient surfaces.

The line integrator and lift supplier must identify the assembly included in each configuration. Their documentation should show what transfers, what stays at the workshop, what belongs permanently to the lift and which party restores each interface. The buyer provides the intended products and work locations; the suppliers provide the coordinated mechanical, electrical and operating boundaries.

If that documented transfer arrangement is absent, select a dedicated installation or an identified external site-production service. A shared purchase needs a priced transfer scope and a responsible integrator. Use that integrator's approved mounting, lifting, connection and operating documents for each installation.

## Reserve the whole absence on the workshop calendar

Block the period from the last workshop order before transfer through the first accepted workshop order after return. Include preparation, approved removal and packing, transport, site setup and acceptance, the site production assignment, return logistics, reinstallation and the restart trial. Use dates from responsible providers, not a single estimated number of “site working days.”

Put the same period against firm workshop orders. If those orders need the former while it is away, sharing requires an alternative production source or a changed customer commitment. Price the actual alternative. Overtime before departure is useful only for orders whose specifications and release dates allow early production.

Keep a separate allowance for a delayed return in the commercial comparison. Define what triggers the backup route and who approves it. Do not describe a backup supplier as available without an offer covering the required profile, material, output and period. Unconfirmed replacement capacity does not protect a committed delivery.

## Complete the transfer-versus-dedication sheet

The worksheet compares one shared physical line with two defined production installations. Fill it using the exact machine identifiers and project dates.

Use the same planning period and order set for both routes. Sharing saves a second former only if the shared route can actually perform the required work. A lower equipment count is not a saving when additional subcontract production, repeated mobilisation and missed workshop capacity exceed the avoided ownership cost.

## Make the return trial part of the purchase

The machine's return to the building is not its return to production. Define a restart trial on the representative profile and material used by the workshop. The quality lead should retain the reference drawing, sample identification and acceptance record from before departure, then compare the returned installation against the same product criteria.

The equipment supplier defines the technical installation and commissioning checks. The workshop owner supplies the people, utilities and product acceptance inputs stated in the agreed scope. This division keeps a commercial planning article from becoming an improvised installation procedure.

Configuration records matter when the site assignment uses different tooling or product settings. Record exactly which parts and controlled settings belong to each installation, who retains them and how the workshop is restored. Do not assume that the available machine frame means every former, cutter or coil-entry combination is interchangeable.

## When a dedicated former earns its place

Dedication is the practical choice when the workshop and site programmes overlap regularly, transfers repeatedly consume the available gap, or either installation has interfaces that make frequent conversion unsuitable. Compare a complete dedicated roof-level package with the shared proposal rather than pricing an isolated spare forming machine.

For occasional site demand, a purchased site-production service is another commercial alternative. Use an actual quotation and keep product acceptance consistent with workshop output. This limits capital exposure without pretending that one shared line can be in two installations at once.

The resulting selection can be deliberately unequal: a workshop line for the full recurring product mix and a dedicated site former for a narrower, confirmed roof profile. That arrangement is useful when the site order book supports it and the nominated equipment proposals cover their respective products. Do not buy universal tooling on both machines merely to make the purchase lists look identical.

## Two sharing plans that fail

**Failure case: only the roof-production days are reserved.** The workshop takes a customer order for the day after site forming ends. The shared line still needs return transport, reinstallation and a restart trial. Reserve the complete absence before accepting the workshop order, or include an actual alternative production source in the commitment.

**Failure case: the second installation is improvised after delivery.** A buyer orders a workshop line and a lift separately, expecting easy transfer between them. The offers do not define the transferred assembly or its interfaces. Resolve the coordinated design before purchase; choose dedicated configurations when a documented shared arrangement is not offered.
