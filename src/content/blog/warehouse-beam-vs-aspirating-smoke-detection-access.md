**Choose a fire-designer-approved beam proposal when its optical corridors remain clear through the actual rack, stock and moving-equipment layout, with accessible device positions. Choose an approved aspirating proposal when its specified sampling positions and pipe route serve the protected zones.** If both satisfy the same fire brief, compare complete installed and maintained costs, including personnel access. A cheaper device count cannot replace the accepted detection design.

For a contractor, the useful comparison is between two completed work packages. One has defined optical devices and paths. The other has defined sampling points, pipe routes and detector equipment. Their installation and service positions differ even when they protect the same building.

## Read the system drawing before pricing a platform

[Honeywell describes imaging beam detectors](https://buildings.honeywell.com/gb/en/products/by-category/sensors/smoke-detectors/imaging-beam-smoke-detector) for large open areas with high ceilings, using infrared light obscuration. [Xtralis describes sampling pipes](https://xtralis.com/product/261/vesda-e-vesda-pipe-fittings) that carry air from the protected area to an aspirating detector. These are different physical architectures. The appointed fire specialist defines the appropriate design, detection requirements and acceptance for the destination.

For the beam option, obtain the actual device, reflector or receiver locations shown by the selected system, their supporting surfaces and the accepted optical corridor. Coordinate that corridor with the maximum operating rack and storage arrangement, cranes and other moving equipment. A clear line in an empty construction hall is not the completed warehouse.

For the aspirating option, obtain the actual detector locations, pipe routing, supports, sampling-point schedule and service access. Work along a distributed pipe route is a different installation task from work at isolated device positions. A low-level detector does not remove every overhead pipe installation or maintenance duty.

The photograph separates the elevated workface from the supporting footprint. Draw the offered machine's actual geometry against the pipe or device positions, using the floor and route data supplied by the site engineer. The system designer's point locations and the equipment provider's configuration must describe the same tasks.

Use the accepted system proposal, not a generic ceiling-area allowance, to count those tasks. Show which ones need sustained shared-deck access and which need short visits to individual points. Allocate each to a named access arrangement.

## Put testing and return visits inside the purchase

The fire contractor must state the installation, commissioning, acceptance and continuing-service deliverables. The buyer then identifies the access needed at each stage and who supplies it. This article prices that work; it does not set detector spacing, alarm thresholds or fire-system test procedures.

Xtralis's [warehouse design guide](https://xtralis.com/file/10478) includes pipe-network integrity and commissioning checks, followed by service and maintenance requirements. Those stages show why installation completion and final acceptance need their own resources. Use the selected system provider's current project requirements for the actual visits.

Reserve access through the accepted programme. If stock is admitted before commissioning or a return inspection, the operations team must provide a real cleared route and working area. Price clearing and reinstatement instead of assuming the warehouse remains empty until every specialist is finished.

Keep the system and equipment schedules connected by task IDs. A platform line item described only as warehouse access gives no reliable answer about which devices or pipe sections it serves. Equally, a device quotation with no installation and acceptance boundary cannot be compared with a completed system proposal.

## Do not buy a whole-facility machine for an isolated point

A few device visits near accessible wall faces require a different equipment comparison from a long overhead pipe installation. Where a task-specific access service covers those isolated positions, price it before committing to platform ownership. Where sustained ceiling work needs a shared deck and the building accepts the offered arrangement, include the equipment in the combined installation programme.

## Two hypothetical bids with an incomplete access allowance

**Failure case: the optical corridor is priced from the empty shell.** A buyer orders the lowest beam-system bid and books one platform before the final rack layout is issued. The operating storage arrangement conflicts with the proposed path and service positions. Resolve the detection design against that layout before awarding the system and its access package; do not buy additional platform height as a cure for a changed optical route.

**Failure case: a low detector removes all elevated access from the budget.** An aspirating-system bid places the detector at an accessible level, but its pipe network still runs across the roof structure. The order omits pipe supports, later inspection positions and a return visit after fit-out. Price those actual tasks from the approved network and commissioning schedule rather than counting detector cabinets alone.
