**Shortlist a large-deck crawler platform for ceiling or wall work that requires a series of reachable positions along a usable floor route. Obtain a specialist mast-climbing proposal for sustained work along a vertical facade. Choose between complete site arrangements, including base design and relocation; a similar platform length or headline height does not make the two systems interchangeable.**

A broad work deck under a ceiling and a platform serving a building elevation solve different access problems. Start with where the workers must stand relative to the surface, then calculate how the proposed equipment serves successive areas.

## Horizontal coverage or repeated travel along an elevation?

Ceiling work takes place beneath a surface. The crew needs access to the underside, tools and the local material interface. A crawler-supported large deck is a candidate when its approved working envelope, support positions and route serve that sequence. Relocation follows the selected equipment's instructions; do not assume travel with an elevated or occupied deck.

A mast-climbing work platform serves a vertical workface from a site installation. The supplier's proposal includes the platform arrangement and mast/base configuration, plus building ties where that design requires them. Do not assume that every configuration needs the same ties, or that a freestanding arrangement suits every height and loading case.

Mast-climbing platforms are an established equipment category for facade tasks such as cladding, glazing and surface treatments. That category description is supported by [Alimak's mast-climbing application overview](https://alimak.com/news/mast-climbing-platforms-for-enhanced-efficiency-and-flexibility-2/); it is separate from ARCLIFT's crawler-platform catalog.

## Draw the workface before pricing the machine

Mark each area on the building elevation or ceiling plan, using the same coordinate reference as the structural drawings. Then complete this comparison with the site planner and each equipment provider.

| Buyer field | Crawler large-deck proposal | Mast-climbing proposal | Input owner and buying consequence |
| --- | --- | --- | --- |
| Required work positions | Enter ceiling/wall areas and floor-to-task dimensions | Enter elevation limits and distance from facade | Site designer defines the workface each offer must serve |
| Base position | Mark support locations and occupied floor area | Mark base/mast locations and installation area | Equipment provider supplies reactions; structural engineer evaluates support |
| Building interfaces | Enter obstructions and required separation at each position | Enter proposed ties where required and structural attachment locations | Building engineer decides which interface is feasible |
| Relocation sequence | Enter proposed positions and permitted movement configuration | Enter installation stages and re-erection locations | Planner prices transitions between work areas |
| Crew and materials | List people, tools and local material distribution | List the same task load and distribution | Equipment provider evaluates the specified loading case |
| Workface interruptions | Mark doors, setbacks, cranes and service routes | Mark facade steps, balconies and changes of elevation | Designer identifies areas needing another access arrangement |
| Supply scope | Enter transport, assembly, instruction and removal items | Enter design, erection, examination and dismantling items | Buyer compares the complete delivered arrangement |

Remove a proposal from the shortlist if its supplier cannot map the required work areas to an actual configuration. A cheaper machine that leaves the return wall or the underside of a roof bay inaccessible has not priced the same job.

## Relocation is part of production cost

For a crawler option, list each move and the work needed to leave one position and establish the next. Include the equipment's prescribed configuration, material removal where required, route preparation and the site activities that block the route. Use durations from the proposed method and the project programme rather than a universal minutes-per-move allowance.

For a mast option, price the initial installation, the time occupying that elevation and any later relocation or reconfiguration. A long uninterrupted facade campaign deserves a different comparison from scattered short tasks on several buildings. Include access to the base and any work that must occur after dismantling.

Do not infer productivity from deck area alone. Compare accepted work completed over the full programme, with erection, repositioning, material replenishment and removal included. Where the project contains both an open ceiling hall and a tall facade, price separate packages before forcing one equipment category to cover both.

## Two wrong comparisons that produce an incomplete order

**Mistake: buying on elevation alone.** A hypothetical contractor chooses a crawler platform because the quoted vertical dimension reaches the top of a facade. The design has not shown the required stand-off positions around the facade returns. The purchase leaves work outside the reviewed envelope. Correct the comparison with an elevation drawing showing every work position and the supplier's corresponding configuration.

**Mistake: comparing bare equipment with an installed access system.** A hypothetical tender places a crawler equipment price beside a mast-climber package containing installation and dismantling. The bare price appears lower, but the buyer has omitted transport, assembly and site engineering from that column. Add the missing scope, then compare both offers against the same work sequence and completion boundary.

## Eight attachments for comparable access quotations

1. Ceiling plan and building elevations with the required task areas marked.
2. Floor-to-task dimensions and facade stand-off dimensions tied to the drawing datum.
3. Structural information for the proposed base positions and any proposed building attachments.
4. People, tools and materials schedule showing where each load is placed during the task.
5. Access route photographs and dimensions, including obstacles and occupied adjacent areas.
6. Work sequence showing each relocation, installation phase and completion deadline.
7. Destination, delivery boundary and allocation of design, assembly, examination and removal work.
8. Requested equipment configuration and acceptance documents for the complete offered package.
