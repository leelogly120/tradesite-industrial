Buy a uniform large-deck fleet when your committed contracts repeatedly require broad, continuous ceiling work and the offered configuration covers their actual positions, loads and sites. Buy a mixed fleet when recurring, paid work also requires a distinctly different access geometry, and that second equipment class earns its complete ownership, delivery and support cost. One occasional awkward position is a reason to obtain a separate access offer, not a reason to own every machine type.

This decision concerns the composition of an owned fleet across several contracts. It differs from choosing whether to buy or cross-hire one missing asset, and from scheduling several trades on one shared project platform. Start with the task portfolio that the business has actually sold.

The photograph below contains different equipment arrangements in an unfinished hall. It shows why the fleet brief needs both workface and ground-route information. Assign each committed task to the machine whose offered work positions and supporting-ground requirements fit it.

## Group work by positions, not customer labels

A warehouse fit-out contractor can have several materially different access duties. A continuous open ceiling strip requires a different working position from a point above an obstruction. A wall installation in a restricted passage adds another geometry. Calling all three duties “indoor work” hides the reason a second machine class is being proposed.

Build task families from measured work positions and supporting conditions. The [IPAF site-assessment course outline](https://www.ipaf.org/en-us/training-courses/site-assessment-mewp-selection) includes height, reach, obstacles, tools, materials, environment and access among equipment-selection inputs. Use those factors to describe each duty before assigning fleet capacity.

Attach the accepted equipment configuration to each family. A large deck needs documented working positions to cover an obstruction, and a smaller platform needs its actual route and task suitability established. If neither proposed class covers a position, keep that task outside the fleet offer until a separate suitable access arrangement has been purchased.

## Complete the portfolio worksheet before ordering a second class

Use one row for each recurring duty and its committed contracts. The entry belongs to the responsible manager, with a drawing, booking or actual quotation behind it.

| Portfolio input | Fill from current evidence | Owner and decision use |
| --- | --- | --- |
| Broad ceiling duty | Work-strip plan, floor-to-task heights and crew/material schedule ___ | Technical lead defines the large-deck task family |
| Different geometry | Obstruction sections, required horizontal positions and approach routes ___ | Site assessor identifies duties outside that family |
| Accepted equipment | Offered configuration drawing and documented task limits for each family ___ | Equipment supplier establishes actual coverage |
| Committed calendar | Signed jobs, dates and independent locations ___ | Fleet planner separates successive work from concurrent demand |
| Delivery package | Actual transported envelope, carrier offer and receiving arrangements ___ | Logistics manager prices each class reaching the customer |
| Support capacity | Maintenance scope, competent service resource and storage cost ___ | Service manager establishes the continuing burden of a second class |
| Uncovered-duty cost | Actual specialist-access offer, attendance and programme effect ___ | Procurement lead prices the alternative to ownership |
| Investment comparison | Complete owned-fleet cost and contracted receipts over one stated period ___ | Finance ranks eligible portfolios on the same demand basis |

Do not use the same signed job to justify two independent machines unless the programme requires both. Conversely, identical machines cannot cover two concurrent sites when only one asset has been budgeted. Equipment type and equipment quantity are separate decisions.

## Where standardization produces a useful operating advantage

A uniform fleet concentrates familiarization, service planning and purchasing around a smaller set of actual configurations. That is a management opportunity, not an automatic saving. Price the supplier's offered support, your staff's competence and the storage and transport arrangements. Do not insert a generic percentage for cheaper maintenance.

For repeat ceiling packages, compare whether standardized equipment delivers the complete accepted work strip without an additional access arrangement. The benefit disappears when each supposedly standard job repeatedly purchases a second machine to reach a predictable obstruction. Those separate offers belong in the uniform-fleet column.

## When a mixed fleet earns its extra complexity

Add a different class when its accepted geometry serves a repeat task family that the large-deck configuration does not cover, and committed demand supports the full extra cost. Compare buying that class with actual specialist access supplied for the same contracts. Include delivery, collection, receiving and the support responsibility on both sides.

The second class also needs a coherent service plan. A low purchase price does not provide a trained maintenance resource or storage between projects. If the business cannot support the class it intends to own, purchase a defined external service package or retain the qualified outside-access route in the portfolio comparison.

Keep the forecast readable: contracted receipts less actual purchase and preparation, continuing care, storage, transport and other documented costs. State the comparison period. Separate any disposal assumption from known receipts. There is no universal utilization threshold that makes a mixed fleet the correct investment.

The low-deck workshop image illustrates another distinction: the equipment's working configuration and its delivery envelope require different records. A photograph of a lowered machine is not a transport specification or a floor-reaction calculation.

## Two portfolio errors to remove from the investment case

**Mistake: one off-axis task triggers a permanent purchase.** A hypothetical contractor adds a different class for a single awkward work position, then forecasts future use from unaccepted enquiries. Price an actual external access package for the isolated duty and compare it with the second class's complete ownership cost. Approve ownership only against a supported demand case.

**Mistake: identical nominal heights are treated as interchangeable capacity.** Another buyer orders matching units while its drawings show a repeated obstruction that their accepted configuration cannot serve. Reclassify that duty by geometry and price suitable access explicitly. A uniform brand or height label does not close the coverage gap.
