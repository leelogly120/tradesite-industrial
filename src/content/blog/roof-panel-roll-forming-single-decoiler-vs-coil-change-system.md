Keep a single decoiler when its complete change sequence fits the order schedule and the material-handling team can serve it reliably. Buy a coordinated coil-change system when repeated changes cause a measured delivery shortfall and a complete proposed entry system removes that loss. Compare the whole change from the last accepted panel of one coil to the first accepted panel of the next.

The purchase is larger than an extra coil position. It includes material delivery to the line, preparation, removal of the outgoing coil, introduction of the next material and restoration of accepted output. If a second position saves preparation time but the line still waits for the same unavailable handling resource, its value is smaller than the stand-alone equipment quotation suggests.

## Separate changes caused by consumption from changes caused by orders

A long run changes coils because the current material is consumed. A mixed-order workshop also changes colour, coating, thickness or material before the coil is empty. The second pattern adds outgoing partial-coil identification, storage and later retrieval to the purchase problem.

Use the production log to group changes by cause. For each group, record when accepted output stopped, which activities occupied the interval and when accepted output resumed. The production lead owns this record; the material controller links it to the incoming and outgoing coil IDs. Keep the record observational. It is not an instruction to perform preparation beside moving equipment.

[Bradbury's double-mandrel equipment description](https://www.bradburygroup.com/Products/Uncoilers/Double-Mandrel-Uncoilers) identifies staging the next coil as the reason for that configuration. Use this as a reference for the equipment category. Whether a particular staging arrangement works in your line must be established in the integrator's layout and operating sequence.

## Buy the missing capability, not a second parking position

There are three commercial routes to compare. Keep the existing single-position arrangement with a properly resourced material service if waiting for the shared handling team is the main loss. Select a staged multi-position or coil-car-supported proposal when the measured loss is the physical change activity that it addresses. Reconsider order grouping when frequent avoidable material switches cause the loss and the promised customer dates permit grouping.

These routes can be combined. Scheduling must respect customer delivery commitments, and any equipment change needs its own approved handling arrangement. Do not assume that a second mandrel provides continuous strip feed or that a joining or accumulation system is included. Those are separate functions and must appear explicitly if the production process requires them.

For roof-level forming, define where each part of the material-entry system sits. Do not carry a workshop entry layout onto a lift by assumption. The line integrator and lift supplier must coordinate the complete supported assembly, feed path and operating positions from actual drawings. A roof-former enquiry is not permission to mount additional equipment on an existing machine.

## A worksheet for the complete material change

Use one representative production period for both alternatives. Enter actual values and attach the event log rather than filling the sheet with a sales estimate.

| Change-system input | Fillable record and datum | Owner | Purchasing consequence |
| --- | --- | --- | --- |
| Change frequency | Consumed-coil changes ___; order-driven changes ___ per recorded period ___ | Production planner | Shows which workload the investment must address |
| Lost production interval | Last accepted panel time ___; first accepted next-coil panel time ___ | Shift lead | Defines the complete interruption consistently |
| Preparation and waiting | Timed activities ___; handling-resource waiting ___ | Production observer | Separates equipment loss from resource scheduling loss |
| Material envelope | Coil outer/inner dimensions ___; width ___; documented mass ___ by material ID | Material buyer | Establishes the entry equipment offered for the actual coils |
| Partial-coil return | Coil ID ___; remaining quantity basis ___; storage position ___ | Stock controller | Prevents unpriced return handling and unidentified stock |
| Entry-area space | Clear dimensions ___ from the fixed building grid; traffic routes ___ | Workshop planner | Rejects a layout that obstructs another required movement |
| Proposed system boundary | Included preparation, transfer, entry control and protection ___ | Equipment integrator | Makes the alternative a complete functioning cell |
| Accepted order benefit | Additional deliverable orders ___; full installed and recurring costs ___ | Commercial lead | Establishes whether the measured gain justifies purchase |

The material envelope is a buyer input, not an ARCLIFT rating. The supplier's identified equipment proposal must cover those inputs and the relevant operating arrangement. Keep staff instruction, guarding and maintenance access in the scope rather than removing them to make one offer look smaller.

## Test the awkward change as well as the easy one

A complete-coil replacement is only one acceptance case. Include a switch from a partially used coil to another material and a return to the identified remainder when that is normal work. Keep the finished-panel product criteria unchanged. A faster change has no commercial value if the resumed output is rejected or the remaining stock loses its identity.

Measure the proposed sequence using the staff and supporting equipment included in the purchase plan. If a demonstration depends on a dedicated crane or material attendant absent from your budget, include that resource in the comparison. Record the point at which the system hands material to the former and who owns each interface.

## Failure cases worth pricing before an order

**Failure case: the second position waits for the same shared handler.** A workshop buys staged coil capacity but leaves incoming-material delivery entirely dependent on a resource already occupied elsewhere. The former remains idle while the next coil is unavailable. Use the waiting-time record to decide whether dedicated material service, revised scheduling or new equipment addresses the actual loss.

**Failure case: mixed-colour production creates unmanaged remnants.** The trial consumes complete coils, while normal customer orders require several partial-coil changes. Returned material blocks the entry area and staff cannot reliably identify which remainder belongs to the next order. Include remnant identification, storage and retrieval in the operating scope and trial before accepting the equipment package.
