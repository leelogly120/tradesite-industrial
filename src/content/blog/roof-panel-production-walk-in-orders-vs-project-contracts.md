**Choose a trade-counter roof-panel business when you can support a defined product range, controlled order acceptance and practical customer collection. Choose scheduled project production when committed quantities, drawing releases and staged site deliveries drive the business. If you serve both, reserve capacity and collection resources for each promise before buying a faster former.** A walk-in customer and a project buyer are purchasing different service arrangements, even when their panels use the same tooling.

This choice comes before scheduling released orders. The [short-order scheduling guide](/blog/roof-panel-roll-forming-short-order-scheduling/) explains how to sequence existing work. Here the investment question is which customers and delivery promises the production operation will be built to serve.

## The trade counter sells an available, bounded range

A useful counter offer names the profiles, approved materials and finishes available for ordering, the information needed to release a job, and the collection arrangements. Set a realistic service window using the whole order journey. Taking payment quickly does not mean that production, inspection, packing and loading are immediately available.

The customer needs a clear order form showing profile identity, length datum, quantities and material. A physical sample or controlled drawing helps prevent an ambiguous request such as “the usual roofing sheet” from entering production. Staff need authority to reject an incomplete request and to explain which nonstandard items require a scheduled quotation.

Keep the stocked range proportional to real demand. Each additional material, colour or profile introduces stock and handling commitments. Customers asking for every possible variant are not the same as customers repeatedly buying a defined range. Record actual requests and completed sales before adding a new tooling family or material inventory.

## Project work sells completion against a release programme

A project buyer usually needs more than a panel quantity. The order contains controlled drawings, installation zones, required components, acceptance requirements and a delivery sequence. The producer must know who releases each revision and which changes stop an existing production instruction.

Schedule from the date when the product definition is ready, not only from the contract date. If a project's final dimensions arrive after the intended manufacturing slot, the business needs an agreed response: a revised delivery programme, a separately accepted partial release or another approved supply arrangement. An unissued drawing should not consume a fictional production slot in the sales forecast.

Plan the delivery endpoint. A project promise can end at factory collection, delivery to the site receiving point or another explicitly defined handover. Price only the service actually offered, and identify who provides unloading and later roof handling. For long panels, the receiving area and installation sequence affect the dispatch arrangement even when manufacturing is straightforward.

## Complete a service-design sheet before requesting line prices

| Business input | Trade-counter entry | Project-contract entry | Owner and decision use |
| --- | --- | --- | --- |
| Core customer | Repeat buyer types and completed order records: ___ | Named projects and committed packages: ___ | Sales lead; separates demand evidence from enquiries |
| Product envelope | Stocked profiles, material and finish range: ___ | Approved drawings, revisions and components: ___ | Technical lead; fixes the product families the line must serve |
| Order release | Signed dimensions, material and collection instruction: ___ | Authorised drawing and zone release: ___ | Order administrator; controls when work enters production |
| Delivery promise | Available collection windows and exclusions: ___ | Zone dates and agreed delivery endpoint: ___ | Operations lead; defines the actual service sold |
| Material commitment | Stock assortment and replenishment records: ___ | Project purchases and approved substitutes, if any: ___ | Purchasing lead; sizes the required inventory |
| Handling space | Waiting, completed-order storage and collection area: ___ | Bundle storage, loading and delivery staging: ___ | Site manager; uses measured route widths and panel lengths |
| Shared resources | Counter staff, inspection and loading availability: ___ | Planning, document control and dispatch allocation: ___ | Production manager; identifies resources beyond the former |
| Representative trial | Typical order and change sequence: ___ | Released project length and quantity sequence: ___ | Buyer and line provider; tests the intended business pattern |

The sheet should produce an equipment scope and an operating commitment together. If the counter has only one loading resource, a large project dispatch can block customer collections even while the former is idle. If project revisions lack a named release authority, extra line speed increases the rate at which the wrong order is made.

## Serving both customers requires two promises, not two machines by default

Consider an illustrative supplier with a repeat stocked profile and a separate weekly project dispatch. Reserve a defined period for released project work and a supported counter-order window. State which orders qualify for the counter service and which enter the project queue. Add an authorised exception route for urgent requests, with the displaced work visible before a new promise is made.

Do not sell the same production slot twice. The buyer should compare the order load against the complete route: preparation, forming, checks, packing and collection or dispatch. Use measured periods from an existing operation or an explicitly estimated trial plan for a new business. The purpose is to identify the resource that prevents the promised service, rather than declare a universal capacity figure.

Start with one line when representative orders fit that plan and the remaining resources support it. Consider a second forming line only after the conflict persists in a complete schedule. If the delay is incomplete order information, customer collection or insufficient loading space, a second former does not remove it.

The [second shift versus second line guide](/blog/roof-panel-roll-forming-second-shift-vs-second-line/) supports the later capacity decision. First decide what each customer channel is entitled to expect. Otherwise the business risks buying equipment to support a service promise that no one has defined.

## Two sales mistakes that cause avoidable equipment purchases

**“Cut while you wait” is advertised for every request.** A customer arrives with a nonstock material and a profile unlike the installed tooling. Staff interrupt released work to investigate the request, while other customers wait for collection. Limit immediate service to the defined range and release rules; quote nonstandard work through the scheduled channel. Do not buy another line merely to maintain an unlimited promise.

**A project delivery is scheduled from an obsolete drawing.** In another illustrative case, sales count a signed order as production-ready while the customer is still changing lengths and roof zones. The machine is purchased against a deadline that the information release cannot support. Tie manufacturing dates to controlled releases and compare equipment proposals against the actual ready-work programme.
