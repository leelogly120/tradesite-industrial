Choose the named cable ladder on a route segment when it alone meets the actual cable load at the available support positions. Choose a named wire basket in a branch-intensive area when its rated package also meets the cable and environmental requirements and its actual bends, drops, supports and installation positions give the lower complete cost. If both packages qualify on a straight run, compare their complete installed offers for that segment. Use both types where different segments justify them; neither category name replaces the product's load and span data.

Both alternatives carry a cable-based distribution route. This is different from replacing that architecture with busbar trunking. The useful buying comparison holds the required cables and route function constant, then prices the support system, installation and personnel access together.

Separate delivery and lifting of the material from access for the crew. The image below shows an upright guarded work arrangement in a passage between buildings. Use the restricted approach as a reminder to map each bend and branch onto a measured work-position section.

*Record approach width, obstructions and the required working position at each restricted route section.*

## Make the cable schedule govern the support offer

The electrical designer defines the cable set, permitted arrangement, segregation and route requirements. The support vendor identifies the actual tray or ladder, fittings and supports it offers for that design. A width by itself is not a support-system specification.

[OBO's cable-support planning guide](https://www.obo.global/out/media/220659%20-%20Leitfaden%20KTS%20EN%20WEB.pdf), section 2.6.5, explains selecting from load information tied to support spacing and product dimensions. Its diagrams exclude human load. Use the supplier's actual data for the selected components, and provide independent personnel access. Do not treat installed cable supports as a walkway.

[Legrand's wire-mesh product page](https://www.legrand.us/cablofil/wire-mesh-cable-tray) includes route fittings, supports and a load-table resource. That supports assessing a complete product package rather than dismissing basket on its appearance. Neither manufacturer's general page establishes the capacity of an unidentified component on your project.

## Divide the route at meaningful interfaces

Separate straight runs, branch-intensive areas, changes in level and interfaces with equipment. Keep the design's cable requirements on every segment. A change of support type needs its actual transition and support arrangement in the offer; it is not a free boundary between two unit rates.

Use the worksheet below to qualify alternatives before awarding them. Fill values from the released cable schedule and vendor submittals, not an estimated mass based on tray width.

| Route-selection input | Project entry | Owner and decision use |
| --- | --- | --- |
| Cable duty | Cable schedule, weights and arrangement requirements ___ | Electrical designer defines the supported system |
| Route sections | Plans, elevations and shared survey datum ___ | Coordinator fixes segment and interface boundaries |
| Support structure | Available fixing positions and accepted reactions ___ | Structural designer defines usable support points |
| Product evidence | Named ladder/basket and matching load/span information ___ | Support vendor qualifies each alternative |
| Fittings and transitions | Actual bends, drops, branches and type-change details ___ | Vendor and installer complete the material package |
| Installation positions | Floor-to-task heights, offsets and overhead conflicts ___ | Installer defines the crew's access duty |
| Future requirement | Documented spare allocation and permitted additions ___ | Owner establishes the actual expansion provision |
| Comparable total | Materials, supports, labour, handling, access and acceptance ___ | Buyer ranks the same completed route |

Reject an unsupported substitution rather than using a larger-looking component as proof. If a support location changes, return to the matching product data and the structural arrangement. A quotation based on an old span cannot be carried unchanged onto a different coordinated drawing.

## Evaluate handling and field fitting as separate costs

Long straight segments and repeated route changes produce different installation work. Obtain the installer's actual quantities and sequence for both eligible offers. Compare complete fittings and support assemblies as well as straight-length material; a low rate per metre hides omissions at a crowded junction. For example, if a basket alternative adds supports between the available structural fixing points, include those supports, their accepted fixings and the associated work positions before crediting its branch-fitting saving.

For a branch-heavy zone, mark where cutting, assembly, inspection and later cable work occur under the contractor's accepted method. For a repeated straight run, mark the actual support and joining positions. Compare the number and duration of usable work setups from those plans. Do not assume that one support type always installs faster.

## Price an access arrangement that reaches the complete route

A broad ceiling platform belongs on the shortlist when repeated positions along a released strip fit its documented configuration. A route crossing an obstruction needs a separate position assessment. Equipment with the right height class still needs appropriate geometry, support, route clearance and task capacity.

The raised-deck image below includes the working surface, crawler base and deployed supports. Those elements occupy different areas. Put the proposed support positions on the floor plan before treating a platform as available beneath a cable route.

![A broad red deck is raised outdoors above its crawler base and deployed supporting feet.](/images/equipment/buyer-20261031-deck-raised-yard.webp)
*Check workface coverage and the complete supported footprint, rather than using deck height alone to select access.*

Keep subsequent cable placement within the project plan. Supporting cable reels and pulling equipment, applying loads to the cable-support system and allocating people to the platform are distinct engineering and task decisions. Assign each to its responsible designer or contractor and include its accepted scope in the comparison.

Compare access occupation through the agreed completion boundary. If one bidder prices only bare-support installation and another includes later inspection and cable work, normalize their scopes before choosing. A narrower initial scope is not a demonstrated saving.

## Two errors that distort ladder-versus-basket bids

**Mistake: the category name replaces the load check.** A hypothetical buyer approves a ladder because “ladder is heavy duty” without matching the selected component to the actual support spacing and cable schedule. Require the named product and applicable load information for that segment. Apply the same eligibility test to the basket offer.

**Mistake: a cheaper straight run omits its branches.** Another bid wins on material per metre but excludes drops, transitions, additional supports and access at the crowded junctions. Complete those quantities from the coordinated route and reprice the installed package. Compare the same route function before calling either alternative cheaper.
