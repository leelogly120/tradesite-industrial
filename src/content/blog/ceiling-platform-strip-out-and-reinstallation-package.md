Keep one ceiling platform through removal and reinstallation when the approved access arrangement suits both tasks, the gap between them is short enough to justify retaining the equipment, and cleaning and inspection fit the programme. Use separate access phases when the tasks require different arrangements or an extended intervening period ties up the platform without useful work. Compare the completed replacement project, including both mobilisations and the gap between trades.

The first action is a two-phase scope sheet. The appointed removal contractor defines its work and material route; the installation contractor defines the replacement system and replenishment route. Procurement then compares a common access proposal with separate proposals on those same inputs. This is a resource decision, not a demolition method.

## Count the period when nobody is using the deck

Ceiling removal can expose work that other appointed trades must complete before replacement starts. Survey, structural work, service changes, inspections or material delivery can create an interval between the two access tasks. The project manager should identify that interval and the condition that releases the next phase.

For retained equipment, price the whole occupied period. Include any agreed hire or ownership allocation, parking space, protection, inspections, cleaning and the opportunity cost of losing its use elsewhere. For separate phases, price removal, transport, later remobilisation and the availability of the replacement access package.

Choose retention only when the common arrangement is technically accepted and its complete retained cost is justified against the complete separate-phase cost. If both bids omit the intervening period, neither is ready for comparison. Do not assign a universal number of idle days as the break-even point; actual transport, storage, availability and commercial offers determine it.

## Compare two task loads, not one ceiling area

Removal and installation can share a workface while having different tools, materials, containment and handling arrangements. The replacement panels can differ from the removed system in size and packaging. Removed material also needs a defined destination. Listing only ceiling area hides those differences.

Give the equipment provider a separate crew, tool and material schedule for each phase, including distribution and any proposed accessories. The responsible project team must approve material handling and removal arrangements separately. Do not assume that a broad personnel deck is a debris skip or a material hoist.

For existing buildings, the owner and appointed specialists must complete the required investigations and define the permitted work before procurement treats the removal phase as a fixed task. The equipment proposal follows those conclusions. It does not assess unknown building fabric or authorise disturbing it.

## The two-phase access worksheet

| Purchase input | Removal-phase entry | Installation-phase entry | Owner and decision use |
| --- | --- | --- | --- |
| Defined task | Released removal scope and limits: ___ | Approved replacement system and scope: ___ | Appointed contractors; tests whether one access arrangement covers both |
| Workface | Existing positions and obstructions: ___ | Positions after intervening works: ___ | Surveyor; elevations from the actual support-floor datum |
| People and items | Crew, tools and approved material arrangement: ___ | Crew, tools and incoming component arrangement: ___ | Task and equipment planners; compares separate load schedules |
| Material route | Identified removal and collection services: ___ | Replenishment, packaging and receiving services: ___ | Logistics lead; keeps handling outside unsupported deck assumptions |
| Occupancy | Entry, active work and phase completion: ___ | Release condition, start and final removal: ___ | Project manager; calculates the complete booked period |
| Between phases | Cleaning, inspection and retained location: ___ | Accepted condition for installation use: ___ | Equipment manager and contractors; defines handover scope |
| Building route | Floor and access conditions during removal: ___ | Changes before installation begins: ___ | Building engineer and surveyor; tests continued route suitability |
| Comparable price | Retained equipment and intervening-period costs: ___ | Separate mobilisation and availability offers: ___ | Buyer; compares the same completed replacement endpoint |

Make any release condition specific. For example, identify the issued inspection record that permits installation to start and the party responsible for issuing it. Avoid describing the gap merely as waiting for others: an unowned milestone makes equipment retention difficult to manage and price.

## Arrange a real handover between the tasks

If the same platform remains, the equipment manager and task contractors need an agreed handover covering condition, cleaning, inspection requirements and the accepted next-phase arrangement. Keep the applicable maintenance and operating documents with that decision. If the new task changes the proposed configuration, obtain the revised technical arrangement before allocating the equipment to it.

*Update the workface and clearance drawing after intervening works, even when the same platform stays on site.*

Great Britain's [HSE guidance on mobile elevating work platforms](https://www.hse.gov.uk/construction/safetytopics/mewp.htm) discusses task selection, site conditions and material-handling requirements. Use the project-specific results of those assessments in both access briefs. A shared machine booking does not replace separate task planning.

## Two mistakes in a combined replacement order

**Mistake 1 — one booking hides a long inactive interval.** In this illustrative project, removal finishes before replacement materials arrive, and the retained platform blocks an area needed by another trade. Correct the purchase by pricing the whole interval and a usable retained location. If separate demobilisation and return fit the project more effectively, buy those phases explicitly.

**Mistake 2 — installation starts under the removal brief.** New components and tools are placed into a work plan based on the old ceiling system. Correct the scope with two task schedules and an accepted phase handover. Use separate equipment when the responsible technical review rejects a common configuration.

### Eight attachments for the replacement-project RFQ

1. Released removal scope and relevant conclusions from appointed building specialists.
2. Approved replacement ceiling system, component sizes and installation sequence.
3. Workface surveys for both phases measured from the supporting-floor datum.
4. Separate crew, tool, material and accessory schedules.
5. Removal-material and incoming-component logistics plans with responsible providers.
6. Programme covering both tasks, intervening trades and the installation release milestone.
7. Assessed floor route, retained-equipment location and planned building changes.
8. Requested cleaning, inspection, transport, power and phase-handover scope.
