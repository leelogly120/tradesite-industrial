**Buy a complete built-up roof supply package when the project needs one coordinated component specification and your team lacks a dedicated roof-system integration function. Form the outer metal sheets in-house when repeat orders justify the line and an appointed designer accepts those sheets within the complete assembly. Keep liners, spacers, insulation, fixings and junction details in the cost comparison; a formed outer sheet is only one part of the roof.**

The roof design in this decision is already a site-assembled built-up system. The question is how much of its product supply the contractor should own. It is not a comparison between a single-sheet former and a factory that bonds insulated sandwich panels.

## The weathering sheet is a production opportunity, not the entire system

A built-up assembly brings several components together on site. For example, [Tata Steel's Trisobuild description](https://www.tatasteeluk.com/construction/products/roof/profiles/trisobuild) identifies an internal liner, spacer system, insulation and external weathering profile. The example shows the category's layered supply structure; its declared performance belongs to its specified system.

For an own-sheet proposal, the building designer identifies the required outer profile, material, support interface and connection details. The roof-system designer then evaluates that nominated sheet with the remaining components. Owning a former does not give the contractor permission to substitute a similar-looking sheet into a proprietary assembly.

Use a complete system package when the provider's actual offer supplies the coordination and evidence the project needs. Read its itemised scope: “system” in a quotation heading does not automatically include installation labour, roof access, every flashing or a particular warranty. Compare the named supplied components and services.

The two forming lines below illustrate a manufacturing investment with physical tooling and separate output arrangements. Decide whether the repeated outer-sheet requirement justifies that investment before expanding the purchase to additional profiles.

## Keep every component in both cost columns

For the complete-package route, start with the supplier's itemised offer. For the own-sheet route, add the forming investment and all components purchased separately. Use the same roof areas, junction schedule and delivery endpoint in each column.

| Package item | Own-sheet route: enter scope and cost | System route: enter offered scope and cost | Owner and decision use |
| --- | --- | --- | --- |
| Outer weathering sheet | Coil, forming, inspection, packing and delivery | Named profile, material and supplied lengths | Production buyer compares the actual sheet output |
| Liner | Identified purchased profile and joints | Named included liner and joints | Roof designer checks the inner layer requirements |
| Spacers and supports | Named supplied components and interface details | Named included support components | System designer evaluates the complete load path |
| Insulation and membranes | Specified products, quantities and locations | Named included products and locations | Building designer checks the assembly specification |
| Fixings and junctions | Fasteners, closures, flashings and penetration details | Included items and explicit exclusions | Installer checks whether the roof can be completed |
| Design and evidence | Named design service and assembly evidence costs | Offered design scope and applicable evidence | Project owner accepts the project-specific documentation |
| Site work | Access, handling, installation and inspection | The same tasks, included or separately priced | Contractor compares the same completed endpoint |
| Changes and replacements | Reproduction, component supply and revision control | Provider's named change and replacement scope | Commercial manager prices the repeat-order obligation |

The table prevents a misleading comparison between cheap coil and an entire supplied roof. Use accepted installed quantities, with actual cutting waste, rejected panels and project-specific replacement allowances entered by the estimator. Calculate waste from the project schedule and production plan. A mixed assembly needs its own accepted design and applicable performance evidence.

## When owning the outer-sheet process earns its place

Invest when the business repeatedly needs the same accepted product family and can operate quality control, material purchasing and delivery reliably. The strongest case is a repeat workload for a defined profile and material combination, with a designer-controlled component schedule and an established installation team.

Buy the system package for isolated projects, varied assemblies or work whose evidence depends on a provider's defined component combination. A small saving in sheet conversion does not compensate for purchasing a design responsibility the contractor has neither staffed nor priced.

If both routes pass the design requirements, calculate the own-sheet cost over committed projects. Include capital recovery, tooling, labour, electricity, maintenance, input stock, inspection, packing and delivery. Add separately purchased system components and engineering. Compare that total with the complete supplier's offer at the same delivery boundary.

## Sequence the outer-sheet and underside work separately

An elevated former serves the outer-sheet production and receiving arrangement. Ceiling or liner access is a different task. Allocate equipment, people and materials to each stage in the installation programme, rather than treating a roll-former lift as a personnel work platform.

The underside view below shows a broad personnel deck beneath steel framing. It illustrates the separate access task inside the building. Put that task in both cost columns when it is part of the contractor's scope.

## Two purchasing mistakes that change the scope

**Replacing a system sheet with a look-alike.** In a hypothetical tender, a contractor prices its own outer profile using the same general rib description as a specified assembly. The designer has not accepted the substituted sheet or its interfaces. The comparison is between different products. Return to the controlled assembly specification; use the nominated sheet or obtain the designer's accepted alternative before pricing the production line.

**Comparing coil plus forming with a complete roof kit.** Another estimate omits liner, spacers, fixings and junction components from the own-sheet column. It appears to show a large saving until those items are ordered. Rebuild the comparison row by row, including design and site work, before committing capital.
