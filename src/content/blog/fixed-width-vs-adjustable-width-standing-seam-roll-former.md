**Choose fixed-width tooling when repeat accepted orders use one stable panel width and that product supports the investment. Buy an explicitly supported adjustable-width configuration when real eligible orders require different uniform widths and the complete stock, setup and inspection case justifies it. Purchase occasional exceptions externally when owning the extra capability is unsupported.** Adjustment capability does not give the producer authority to change a customer's roof product.

This decision concerns panels that each have a constant width along their length. It differs from tapered-panel production, where the geometry changes along the panel, and from choosing a machine for several different profile families. Keep those purchases separate.

## Start with widths customers have accepted

Build an order register showing the panel drawing, material, specified width, quantities, lengths and release dates. Name the product authority accepting each width. Separate actual orders from widths the sales team hopes to add later.

A manufacturer example establishes the adjustable category: [NTM's SSH roof-panel machine page](https://newtechmachinery.com/machines/roof-wall-panel-machines/ssh-roof-panel-machine/) describes variable panel widths within its offered profiles. That is capability of its named equipment. It is neither an RF8 specification nor evidence that any width is accepted within your selected roof system.

Ask each proposed provider to map the actual released widths to its tooling configuration. A quotation stating “adjustable” needs to identify the product features, input material and equipment it covers. Do not infer that both edges, every seam or every related component remain compatible after a width change.

## Three dimensions belong in the stock decision

Label input strip width, manufactured panel dimensions and specified installed cover separately. Use the datums on the controlled section drawing. The material buyer and product engineer should reconcile those references before comparing coil purchases or accepted covered area.

An adjustable machine does not make every incoming strip useful for every panel. Obtain the material requirement for each released product. Compare buying the required input widths with any separately specified preparation process. Keep a slitting investment outside the former quote unless the actual offered package includes it.

## Compare one fixed product with the supported adjustable range

| Decision field | Fixed-width entry | Adjustable-width entry | Owner and decision use |
| --- | --- | --- | --- |
| Eligible products | Accepted width and drawing revision: ___ | Each accepted uniform width and revision: ___ | Product authority; defines the output that can be sold |
| Actual demand | Repeat orders and release dates: ___ | Order mix by width and release date: ___ | Sales planner; supports the additional capability |
| Material input | Required strip, grade and finish: ___ | Input specification for each product width: ___ | Material buyer; establishes real coil stock commitments |
| Tooling scope | Identified fixed configuration: ___ | Identified adjustment configuration and exclusions: ___ | Equipment provider; states what the offer actually makes |
| Change event | Changes still required between orders: ___ | Complete transition to the next accepted width: ___ | Operations lead/provider; prices the actual unavailable period |
| Acceptance | Controlled dimension datums and samples: ___ | Same basis at every required width: ___ | Quality lead; prevents a successful middle-width sample covering untested products |
| Handling | Actual order lengths and receiving route: ___ | Same lengths plus width-specific objects: ___ | Workshop lead; assesses the complete production layout |
| Ownership case | Equipment, stock, support and outside exceptions: ___ | Equipment, added stock/change resources and support: ___ | Finance lead; compares the same accepted orders |

Use the complete change event. Obtain its start and finish from the actual provider's scope, including material preparation and accepted restart where applicable. A control value or short demonstration is not the whole production transition.

## Flexibility earns its place through repeated eligible work

An adjustable proposal is valuable when the order register repeatedly needs the supported width changes and the full operation can deliver those orders. Retain the fixed proposal when one released width dominates and purchasing exceptions serves the remaining customers more effectively.

If both proposals serve the same orders, compare their complete costs and support requirements. Include the buyer's available people, inspection resources, material stock and delivery commitments. Do not credit the adjustable line with speculative sales while assessing the fixed line only against existing orders.

## Two failures in hypothetical width-flexibility purchases

**Hypothetical failure case: machine adjustment becomes a product substitution.** A buyer changes panel width to use available coil, although the released roof and component package still specify the original product. Obtain the responsible product decision before changing manufacturing input or output.

**Hypothetical failure case: one sample represents the whole range.** Another buyer accepts a demonstration at one width and budgets several different ordered widths without their material and acceptance records. Include representative required products in the agreed trial and price exceptions through a separate supplier until the complete route is supported.
