Choose a combined former-and-lift proposal when you are buying both machines and need one party to coordinate their integration. Retain an existing former when its owner can release the machine drawings and control documentation, and a named integrator accepts the combined-system review. Reject a supposedly complete package if nobody owns the cutting-function interfaces and acceptance tests. A quotation that omits those interfaces leaves an unresolved scope; it does not mean they are unnecessary.

A cutter can arrive as hardware while its controls, installation and relationship with the lifted former sit in different orders. Close those boundaries before comparing prices. The cover's profile-shaped tooling also shows why cutter selection starts with the intended panel drawing.

<!-- audit-section: conditions -->

## Two purchasing routes, one named integration owner

**Buy the former with the lift** when tooling selection, machine mounting and control coordination all belong to the new project. Request a combined technical schedule that identifies the former, cutter and lift separately, then assigns the interfaces between them. Name who designs, supplies, installs and tests each connection. One commercial contact is useful only when the offer also allocates those responsibilities.

**Retain your current former** when its profile capability suits the roof package and its documentation can support the proposed installation. Include the current electrical drawings, control description and modification history with the RFQ. Price the interface review and any resulting changes as explicit work. If the machine owner cannot release that documentation, choose a documented replacement package or recover the records before buying a lift around it.

## Turn "cutting included" into a comparison table

Use the [electrical and control interface guide](/blog/roll-forming-line-electrical-control-interfaces/) to align the overall supply boundary with the cutting-function responsibilities below.

Complete the blank fields with the project team; have the integrator return the last column with its offer. Identify each signal as a command, machine status or part of a safety function.

| Buyer input to complete | Datum or document to reference | Responsible owner to name | Decision and offered deliverable |
| --- | --- | --- | --- |
| Panel profile/revision: ___; material specification: ___ | Controlled profile section and material sheet | Roofing designer supplies; former supplier reviews | Select the tooling and cutting method for the stated profile |
| Target lengths: ___; length tolerance: ___ | Define the two panel ends and measurement method | Buyer sets acceptance; former supplier proposes method | Agree a sample-cut acceptance record before ordering |
| Cutting commands and status: ___ | Existing or proposed function description, with sender and receiver | Former supplier and integrator | List included functions and identify every machine they affect |
| Stop and restart responsibilities: ___ | Combined-system risk assessment and function specification | Named competent integration lead | Define required behavior, affected equipment and validation scope |
| Operator positions: ___; handover zone: ___ | Marked plan and roof section with outlet datum | Site manager supplies layout; integrator reviews | Decide control locations and coordination arrangements |
| Cable/interface installation: ___ | Connection schedule and route drawing | Equipment suppliers and installation contractor | Allocate hardware, installation, testing and replacement documents |

Keep production functions and safety-related functions separately identified in that schedule. The buyer specifies the work sequence and acceptance needs; the competent designer determines the required control design. HSE's [machinery safety guidance](https://www.hse.gov.uk/work-equipment-machinery/introduction.htm) calls for clearly identified controls and competent people to make and check programmable-control changes. This supports assigning an integration lead; it does not select a circuit for this project.

The trade-off: a combined purchase concentrates coordination; retaining a former preserves equipment matched to your profiles but adds interface work. Compare installed scopes, including test attendance and revised manuals, rather than machine prices alone. Carry the agreed cutting scope into the complete [roll-forming line specification](/blog/roll-forming-line-specification-long-span-roof-panels/).

## Two failures to prevent before the order

These are planning examples, not reported customer incidents.

**Failure 1: cutter hardware is mistaken for installed integration.** A contractor orders a lift and a former from separate suppliers. Both quote "cutting included," but neither includes the connecting work or combined acceptance test. The equipment reaches site before that gap is found. Prevent this by assigning every table row to a named company and including its deliverables in the priced scope.

**Failure 2: a successful workshop cut closes the wrong acceptance item.** A sample panel meets its length tolerance, so the buyer accepts the entire package. The test record covers neither the planned roof handover nor the agreed stop/restart functions. Separate dimensional acceptance from integration validation, with the responsible specialist approving the latter against the agreed function specification.

A retained former does **not fit** this purchasing route if nobody will own its integration into the proposed installation. Resolve that ownership or change the package before ordering. Likewise, an ordinary cutting command must never be assumed to provide the safety function required by the combined assessment.

The elevated arrangement below places forming equipment above ground-level coils. Use a roof section to relate the operator stations and panel handover to that vertical separation; a workshop layout alone misses this site decision.

*Mark the ground operator station, elevated outlet and receiving zone on the same project section.*

## Eight attachments for a comparable RFQ

- Former identification, current control documentation and modification history, or the proposed new-line scope.
- Controlled panel profile, material specification, target lengths, tolerances and sample-cut acceptance method.
- Building section showing required outlet height, roof slope and the measurement datum at each zone.
- Ground operator and roof receiving positions, communication arrangement and planned panel handover sequence.
- Site access plan showing setup pads, ground support information and the outrigger working area.
- Destination power data and a marked service route between supply, lift and former.
- Chassis inclusion, transport arrangement and destination country with required equipment documentation.
- Completed responsibility table naming the integration lead, installation contractor and acceptance witnesses.
