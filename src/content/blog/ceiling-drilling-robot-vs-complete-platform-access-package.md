**Use complete personnel access as the base for a mixed ceiling-installation contract. Add a drilling robot only when released digital inputs, site acceptance and a representative trial support its task, and the complete combined package costs less for the same accepted output or meets a required date that the platform-only route cannot meet. Retain fixing, assembly, connections and finishing in the budget. For drilling-only awards, compare complete drilling packages at the same completed-hole endpoint.**

This decision concerns how much of the contract an automated task actually covers. It is separate from choosing a larger deck or a different power option for an existing platform. A robot quotation and a finished overhead installation are different deliverables. Start with the awarded work and divide it into measurable outputs before comparing equipment amounts.

## Identify the work that the robot actually buys

[Hilti's Jaibot description](https://www.hilti.com/content/hilti/W1/US/en/business/business/trends/jaibot.html) describes a semi-automated machine using digital plans to mark and drill holes for installation work. That is a documented task category. The buyer still needs the selected provider's actual machine scope, accepted inputs and site response for the intended contract.

List hole formation separately from setting out the whole installation, fitting supports, placing components, connecting services and completing the specified checks. Allocate each activity to its actual provider. A drilling contract that ends at accepted holes leaves a different remaining workload from a contract for completed ceiling or building-services installation.

For a drilling-only award, compare both methods at the same endpoint: the specified accepted holes, records and handback. For a complete installation award, compare whole-job scope. Retain the personnel access and handling needed for the remaining activities even when a drilling package is purchased.

## Complete a work-package comparison before pricing automation

Give the drilling provider and access provider the same released work zones and programme. Enter the information below for the actual project rather than a sample building. Keep equipment eligibility, output acceptance and commercial comparison as separate decisions.

| Decision input | Buyer entry | Required proposal response | Owner and decision use |
| --- | --- | --- | --- |
| Awarded endpoint | Drilling only or complete installed system: ___ | Included outputs and remaining activities: ___ | Contract manager prevents an incomplete comparison |
| Hole data | Drawing revision, coordinate reference, units and approved fixing locations: ___ | Accepted digital input and preparation work: ___ | Designer and survey lead define the controlled input |
| Workface | Hole locations and underside elevations from the project floor datum: ___ | Supported working envelope for the offered configuration: ___ | Surveyor and provider establish physical eligibility |
| Building stage | Current services, overhead obstructions and released zones: ___ | Assessed access and exceptions for those zones: ___ | Site coordinator links the proposal to the actual work stage |
| Ground route | Entry, turning and setup locations with floor records: ___ | Machine footprint and applicable loading information: ___ | Site engineer assesses the complete route and positions |
| Remaining installation | Supports, components, connections, finishing and checks: ___ | Personnel-access and handling scope for those tasks: ___ | Installation lead keeps the whole contract resourced |
| Trial and output | Representative locations, required records and acceptance criteria: ___ | Complete-cycle trial scope and measured results: ___ | Project lead compares accepted work rather than isolated drilling |
| Cost boundary | Data preparation, mobilisation, staffing, access and closeout: ___ | Included items, exclusions and quoted period: ___ | Buyer compares the same work and completion date |

Keep the setting-out reference explicit. Record who issues the coordinated hole schedule and who authorises a revision. The robot provider receives an input for its defined task; the project designer retains the fixing design and permitted locations. This article does not provide drilling, anchoring or structural-design instructions.

## Judge the whole trial, including the work left behind

A useful demonstration starts from the same state as the planned project. Include required data preparation, machine arrival, setup, normal changes of position, identified exceptions and the specified handback records. Agree the trial boundary before recording the result. Counting only tool contact time excludes work the buyer still funds.

After the drilling trial, map the remaining installation activities onto the programme. Identify the crew, access arrangement, material presentation and acceptance stage for each. A saving in one task is useful only within the complete supported plan; it does not remove another team's access requirement.

The broad-deck photograph below shows why that second scope remains visible. The deck, lifting structure, crawler and supports occupy a complete setup footprint. Compare the quoted arrangement with the actual installation tasks and floor assessment, rather than treating a drilling-machine allowance as the whole overhead-equipment budget.

![An orange broad-deck crawler lift with extended supports stands outside a metal-clad factory.](/images/equipment/buyer-20261110-broad-deck-yard.webp)
*Carry the personnel-access footprint and its site assessment into the remaining installation package.*

Compare the same commercial period on both sides. Include the actual preparation, transport, competent attendance, specialist support and remaining access in each proposal. Use quoted amounts and measured project inputs. No universal hole count, labour reduction or payback period establishes the buying decision for every building.

## Two hypothetical failures in an automation purchase

**Hypothetical failure case: drilling is mistaken for completion.** A contractor removes the whole platform allowance after receiving a robot quote. The installation crew still needs access to fit supports and place the ceiling components. Restore those activities to the work breakdown and fund their accepted access before comparing the revised whole-job totals.

**Hypothetical failure case: the trial avoids the actual site.** A demonstration uses a clear test area, while the awarded work includes occupied bays and revised services. The comparison omits relocation and exception tasks. Require a representative released-zone assessment and a complete-cycle trial, with its exceptions assigned and priced.
