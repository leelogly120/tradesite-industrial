**Buy access for the accepted complete wall assembly. An insulated sandwich-panel installation and a rainscreen package can allocate backing-wall, support, cladding and joint work differently. Price those retained tasks and their handling interfaces before selecting equipment.** A facade area rate or a wall height alone cannot establish the complete installation package.

This is a construction-scope comparison, separate from choosing a vacuum lifter or manufacturing wall cassettes. The contractor needs to know what it must install, in which building stages, and where people must work. Material presentation remains an identified specialist function beside personnel access.

## Read the wall section before the panel schedule

Ask the responsible designers to issue the actual wall assembly, including backing construction, insulation, supports, outer surface, openings and junctions. The name rainscreen or insulated panel should lead to those documents, not replace them. A supplier's product family can contain several assemblies with different installation boundaries.

[Kingspan's Dri-Design information](https://www.panels.kingspan.com/en-gb/products/wall/rainscreen-facades/dri-design) describes a rainscreen product used with identified backing-wall structures and different attachment arrangements. Its [rainscreen range](https://www.panels.kingspan.com/en-gb/products/wall/rainscreen-facades) illustrates that the visible outer material is only part of the selected system. These examples belong to Kingspan's products; they establish no ARCLIFT cladding supply or project compatibility.

Obtain an operation schedule from the actual installer. Identify which work is completed by others before your package begins, what your crew installs and what remains for another specialist. For sandwich panels, use the nominated panel system's complete details. For rainscreen, retain the actual backing, subframe and cladding boundaries rather than assuming a universal sequence.

## Buy the work hidden behind the finished elevation

A finished facade photograph shows the outer appearance while concealing many construction tasks. Supports, opening details and specified inspections can require access before outer panels are in place. The equipment period must follow those stages, including any required releases before work is concealed.

Do not let a price for placing panels become the budget for the whole wall. Conversely, avoid charging the access package for work already completed and accepted by another contractor. The correct comparison uses the same starting condition and the same finished handback.

## A wall-system purchase matrix

Fill this table from the released design and real supplier scopes. Compare the complete installation rather than transferring one system's equipment allowance to the other.

| Package field | Fillable project record | Responsible owner and datum | Decision it changes |
| --- | --- | --- | --- |
| Accepted assembly | System ___; wall section revision ___ | Facade designer; released project specification | Establishes what must be built |
| Starting condition | Backing/structure already complete ___ | Main contractor; accepted handover record | Defines the installation boundary |
| Support work | Brackets, rails or nominated supports ___ | System designer; issued elevation and sections | Identifies work before outer-panel placement |
| Component supply | Panel/unit sizes ___; masses ___; packages ___ | Product supplier; actual delivery schedule | Defines specialist handling objects |
| Joints and openings | Detail references ___; responsibility ___ | Facade coordinator; opening/junction drawings | Prices completion beyond the main field |
| Inspection releases | Required checks ___; approving party ___ | Quality lead; project inspection plan | Establishes visits before concealment |
| Personnel positions | Faces ___; levels ___; exceptional locations ___ | Installer and surveyor; building/local-floor datums | Tests candidate access coverage |
| Complete purchase | Installation ___; handling ___; access ___; handback ___ | Buyer; identical finished-wall boundary | Supports a comparable commercial decision |

The matrix should expose exclusions rather than disguise them. If the facade contractor does not supply the backing wall, identify its accepted handover and date. If one bidder includes opening completion and another excludes it, add the actual outside quotation before ranking the offers.

## Coordinate handling for each actual object

Large panels, smaller facade units, support components and packaging need their actual dimensions and mass information. Obtain the product supplier's handling requirements and the appointed specialist's proposal for presentation at the workface. Do not select the handling method from an unrelated photograph or a generic panel label.

The personnel-access supplier needs the crew, tools and simultaneous objects proposed on its equipment. Keep separately handled components in their own assessment. A broad deck, guardrail or accessory should not silently become a support for the wall product in order to close a gap between two quotations.

Put both proposals on the same site layout. Include material staging, equipment positions, access routes and adjacent work for the actual construction stage. An access machine and a material machine can each fit separately while their combined proposals claim the same space.

## Two hypothetical facade budgets with different omissions

**Failure case: outer-panel placement becomes the full rainscreen budget.** A buyer copies an insulated-panel allowance into a facade order whose actual design also requires a separately installed support package and inspection releases. Read the complete wall section and price every retained operation before setting equipment occupation.

**Failure case: the handling package is carried over unchanged.** Another contractor changes from one wall assembly to another but retains a quotation for the old component dimensions and presentation. Supply the actual new objects to the handling specialist and coordinate its revised proposal with personnel access before purchase.

Consider the [ARC-F25 crawler large-deck ceiling and wall platform catalog model](/products/arc-f25-crawler-ceiling-platform/) where the task needs adjacent personnel positions and the proposed arrangement serves the released workfaces. Request deck geometry, task-load limits, support reactions and transport configuration. Compare a specialist facade-access alternative where sustained elevation work or exceptional positions call for a different arrangement.

Attach eight items to the RFQ:

1. Accepted insulated-panel or rainscreen wall assembly.
2. Current wall elevations, sections and opening/junction details.
3. Starting-condition handover and retained operation schedule.
4. Component dimensions, masses and manufacturer handling information.
5. Named specialist material-presentation scope and shared layout.
6. Personnel work positions referenced to floor and building datums.
7. Route, ground/floor records, environment and proposed setup areas.
8. Inspection releases, work dates, destination and delivery/removal boundary.
