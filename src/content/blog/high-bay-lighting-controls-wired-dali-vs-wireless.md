Choose the qualifying controls architecture with the lower complete installed-and-supported cost for the same accepted zone functions. Buy wireless when the actual building trial passes and priced control-cable and shutdown savings exceed its added network, gateway, commissioning and support costs. Buy wired DALI when its accepted routes and complete component package produce the lower total. Retain mains work in both offers and compare complete commissioned systems.

The decision follows an agreed high-bay lighting renewal. Fixture replacement scope and required lighting outcomes are already fixed. The purchase here is the communication and control architecture: its devices, routes, commissioning tools, integration and future support. A box of wireless nodes and a fully commissioned wired offer are different commercial endpoints.

## Specify what the owner must be able to do

Write a short operating brief before selecting a protocol. Identify the zones, occupancy responses, daylight responses, manual commands and interactions the building actually needs. Describe who changes those functions when production moves. Give each requirement an acceptance demonstration, such as a named zone responding to its designated input while an adjacent zone retains its specified state.

This turns claims of flexibility into purchase evidence. A building with stable production cells and accessible control routes has a different installation case from an occupied hall whose cable work requires extensive shutdowns. Neither condition establishes product compatibility. The proposed components must still support the selected functions as one documented system.

The access plan should locate the devices that need installation, setting, replacement or inspection. A network drawing establishes logical relationships; the building section establishes where people must work. Keep both drawings tied to the same device IDs so an installation saving is not mistaken for the removal of all future overhead access.

## Request the actual system drawing for each route

[DALI Alliance's wired-system description](https://www.dali-alliance.org/dali/systems.html) distinguishes control gear, application controllers, input devices and the bus power supply. The control bus carries communication and bus power; it does not replace the luminaires' mains supply. A wired quotation must identify the included control routes and devices as well as the electrical installation scope.

Wireless offers also need precise identities. [DALI Alliance's wireless guidance](https://www.dali-alliance.org/wireless/) distinguishes wireless DALI from wireless-to-DALI gateways that translate between a non-DALI wireless network and DALI devices. A gateway proposal therefore requires a drawing of both sides and a supported compatibility list. A product carrying a wireless label is not automatically interchangeable with another ecosystem.

For an example of a real commercial category, [Tridonic describes basicDIM Wireless](https://www.tridonic.com/en/int/controls/indoor/basicdim-wireless-lighting-control) as Bluetooth-based interior lighting control with mesh communication and app commissioning. That establishes an offered approach, rather than suitability for a particular hall. Assess the actual proposed configuration and its stated support terms against the building brief. Record the exact commissioning tools and software versions included in the accepted configuration.

A mixed wired/wireless route belongs in the comparison when a supported gateway solves a specific difficult section. Price its additional components, configuration ownership and service boundary. Retain that mixed route only if it meets the same acceptance brief and reduces the complete quoted cost or satisfies a building constraint that excludes the other offers.

Use a survey or trial that represents the installed arrangement, including relevant building obstructions and normal operations. Record the conditions and devices used. A successful connection from the hall entrance says little about an overhead endpoint behind the equipment that remains in place after commissioning.

## Own the configuration after the installer leaves

Ask the bidder to demonstrate a normal owner change during acceptance: for example, reassigning an agreed zone using the proposed authorised tools. Establish who receives the configuration records, backup files, account permissions and recovery procedure. State any licences, subscriptions or vendor service dependencies that the actual offer requires. These are commercial scope items, rather than universal features of all wireless or wired systems.

Define fault ownership across the complete drawing. If a command crosses a building-management interface, gateway and lighting controller, identify who diagnoses that chain and what handover evidence each party supplies. Otherwise, a working initial demonstration can leave the owner paying several firms to locate the first later fault.

Compare ownership costs through the same period. Include installation disruption, commissioning, documented support charges, expected device replacement work and a priced example of a normal layout change. Value a future layout change only from a defined task and its quoted cost in each system. Keep the basis visible so another buyer can reproduce the comparison.

## Avoid two expensive shortcuts

**Mistake (hypothetical): treating wireless control as the removal of all electrical cabling.** A buyer approves the wireless alternative after deleting both control cable and luminaire power work from the budget. Correct the estimate by retaining the accepted mains installation and removing only the control-route work that the actual wireless design replaces. Recompare complete installed systems.

**Mistake (hypothetical): buying a gateway before fixing the compatible endpoints.** A hall owner purchases a wireless-to-DALI gateway, assuming it makes every proposed wireless sensor work with the selected drivers. Correct the package with a supported component matrix, both network drawings and an acceptance test for each required interaction. Award the demonstrated system rather than assembling compatibility from product names.
