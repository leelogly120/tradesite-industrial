**Shortlist radiant tubes for defined spot-heating zones when the heating designer accepts their coverage, clearances and building interfaces. Shortlist warm-air unit heaters when the brief calls for distributed warm air and their discharge and service routes fit the operating layout.** Buy only a proposal accepted for the actual heating brief. If both qualify, compare complete ownership cost, including specialist installation and personnel access; appliance price and unit count omit different overhead work.

Start with the building's heating requirement, not a platform model. The owner and heating specialist define occupied areas, operating periods and the proposed equipment. Then the installation contractor prices the actual workfaces, component handling and visits that each layout creates.

## Two heating layouts create different access maps

A defined group of workstations needing local warmth is a different purchase from a brief requiring distributed heated air across a larger occupied area. Compare proposals against the same occupied zones and operating periods. If one offer heats only the nominated workstations while another includes the wider area, reconcile that scope before ranking either installation price. The heating designer establishes the required output; the contractor buys the matching installation work.

For the radiant option, mark each proposed run, its supports, burner or service assemblies and the connection locations specified by the heating provider. For the warm-air option, mark the units, building connections, service faces and separately specified distribution equipment. Obtain the selected system's actual fuel, electrical, air and exhaust interfaces from its responsible specialists.

## Price the installation in work packages

Separate supports, equipment placement, specialist connections, controls and commissioning. Allocate personnel access to the stages that actually need it. Record whether the heating contractor supplies access for its own work or expects the main contractor to provide it.

Long components and compact units need different delivery and presentation arrangements. Have the heating installer identify the actual component dimensions, masses and orientation at each stage. Allocate lifting and positioning to the nominated handling provider. A broad personnel deck is not a default substitute for that handling purchase.

## A worksheet for comparable offers

Complete one version for each layout against the same heating brief. The input owner supplies the named drawing or schedule. The buyer uses it to choose a deliverable installation package.

| Decision field | Buyer entry to complete | Responsible source and reference | Effect on the order |
| --- | --- | --- | --- |
| Heating objective | Occupied zones, operating periods and required outcome ___ | Owner and heating designer; project brief | Keeps both proposals on the same service basis |
| Equipment layout | Actual runs or units and installation faces ___ | Heating designer; coordinated plan and sections | Locates the work instead of counting appliances |
| Building connections | Supports, connection points and access faces ___ | Structural and heating providers; issued details | Defines fixing and connection stages |
| Service interfaces | Actual fuel, electrical, air and exhaust scopes ___ | Appointed system specialists; interface schedule | Assigns work beyond equipment placement |
| Personnel positions | Task elevations and horizontal offsets ___ | Installer and surveyor; supporting-floor datum | Tests the proposed platform configuration |
| Presented components | Dimensions, masses, orientation and handling provider ___ | Heating installer; delivery and lifting schedules | Separates component handling from personnel access |
| Possession periods | Work, inspection, commissioning and return dates ___ | Main contractor; released zone programme | Prices continuous occupation or separate visits |
| Ownership comparison | Installation, care, access and interruption costs; period ___ | Buyer and facility manager; actual offers | Selects the complete qualifying route |

Keep rejected layouts out of the price ranking. If a proposal fails the heating brief or cannot be installed within the required building interfaces, a cheaper platform allowance does not repair it. Where both qualify, compare the complete work over the owner's stated period using project quotations and the facility's own operating assumptions.

## Include the maintenance visits that stay overhead

Ask the heating provider to identify the actual service faces, removable items and required access space for the selected products. Retain those locations in the completed facility layout. A construction route that is open today can become a production line or storage aisle before the first service visit.

## Two hypothetical heating purchases that miss the work

**Failure case: a low appliance price wins against an incomplete installation.** A contractor compares a tube supply quote with an installed unit-heater proposal. Supports, service interfaces and later commissioning access are absent from the first total. Rebuild both offers around the same commissioned heating outcome, with each specialist stage and access provider named.

**Failure case: the installation platform becomes the maintenance plan.** An owner buys a large deck from an empty-building drawing, then puts permanent equipment under the heater service faces. The machine's construction use does not create a future setup position. Reserve a real operating route and support area, or purchase a different accepted maintenance arrangement before the layout is fixed.
