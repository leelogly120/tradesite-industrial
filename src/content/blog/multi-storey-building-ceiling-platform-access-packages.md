**Use a ground-based large-deck proposal for a full-height hall or atrium when an unobstructed, approved working arrangement connects the base to every required task position. Specify floor-by-floor access for ceilings separated by structural floors. Choose equipment from the supporting level to the local workface; the building's total height is not the required platform height on every floor.**

This distinction prevents an expensive category error. A tall machine standing outside or on the ground floor does not automatically provide access to interior ceilings above intervening slabs. Conversely, a multi-storey building can contain an open hall that needs a separate high-level access package alongside its ordinary floor packages.

## Divide the building by accessible volume

Start with a building section showing finished floors, structural slabs, roof framing and the ceiling work. Mark each continuous space in which a proposed platform can operate. A floor plan alone does not show the vertical barriers that separate the workfaces.

For an open hall, the base, lifting structure and deck occupy the same continuous volume as the roof task. The photograph below shows this relationship in a real steel building. The broad platform sits beneath roof members; its route to that position is part of the equipment proposal.

![Red work platform viewed from below among white roof beams and panels.](/images/equipment/buyer-20261029-ceiling-interface.webp)

*Mark the actual underside workface on a building section, including the structure between it and the supporting level.*

For a floor-separated space, start again from that floor. Identify its local ceiling task, access method and equipment delivery route. Do not transfer a ground-floor machine proposal to an upper slab by changing only the height entry. The supporting structure, route and loading conditions are different.

An atrium with galleries needs both checks. A ground-based proposal can address only work within its reviewed envelope and clear volume. Ceilings behind the galleries remain separate tasks when slabs or walls interrupt that path. Draw those boundaries before counting how many access packages to buy.

## Build a package schedule from the section drawing

Create one row for each structurally separated work zone. The table below is a fill-in schedule: replace the example zone names with the actual drawing grid and level identifiers.

| Zone / buyer entry | Required measurement and datum | Responsible input owner | Procurement decision |
| --- | --- | --- | --- |
| Open hall: enter grid limits | Supporting surface to underside task; mark horizontal task boundary | Building designer and site surveyor | Defines the ground-based large-deck enquiry |
| Upper floor: enter level and room group | Finished-floor datum to local ceiling; identify slab and openings | Building designer | Establishes a separate local access package |
| Atrium edge: enter gallery location | Workface relative to gallery slab edge and open void | Designer and access planner | Separates reachable open-volume work from enclosed work |
| Machine support: enter candidate positions | Proposed support reactions and load distribution at each level | Equipment provider supplies loads; structural engineer assesses the structure | Accepts or rejects that equipment/location combination |
| Delivery route: enter each transfer stage | Actual clear dimensions, handling method and receiving level | Logistics planner and handling provider | Determines whether the equipment can reach its operating floor |
| Materials: enter panel or component package | Material dimensions, mass and delivery point for each zone | Material supplier and installation lead | Separates material transfer from personnel access |
| Programme: enter start and release dates | Dates for floor access, installation and removal | Project planner | Determines shared equipment versus separate concurrent packages |

Do not collapse these rows into one building-height number. A supplier needs the geometry and duty of the package it is pricing. The structural engineer needs the proposed equipment's actual support loads, not a photograph or an average floor-area calculation.

## Delivery to an upper floor is its own scope

Once an upper-floor access method is selected, specify how the equipment reaches that level and how it leaves. Use a logistics provider's engineered handling arrangement for the proposed machine or components. Include receiving space, permitted equipment configuration and the actual route from the delivery point to the work zone.

A construction hoist opening, temporary facade opening or lifting plan is not available merely because it appears possible on a drawing. Assign the transfer to a provider whose accepted scope identifies the equipment dimensions, mass and handling interfaces. Price that scope before comparing ownership with another floor-specific access option.

The tracked base and support legs below show the equipment-ground interface. On an upper floor, the corresponding interface is with a designed structure. Both the local supporting area and the route across that structure need the responsible engineer's assessment against the proposed loads.

![Tracked base of red lifting equipment with support legs extended inside an unfinished building.](/images/equipment/buyer-20261028-crawler-base.webp)

*Provide the structural engineer with the offered machine's support and travel loads for the actual level and route.*

Keep panel delivery separate from access for installers. Moving workers into a position does not establish how a large ceiling panel reaches the same position. Give each package a personnel-access scope, a material-delivery scope and an identified interface between them.

## Two purchases that start from the wrong height

**Mistake: using total building height for all interiors.** A hypothetical buyer requests one tall platform for a building with several completed floors. The equipment proposal serves the open entrance hall, but structural slabs separate the remaining ceilings from its base. Divide the order by accessible volume and obtain local floor packages for those workfaces. Retain the high-level proposal only for the hall it actually serves.

**Mistake: transferring a ground-supported proposal onto a slab.** A hypothetical project selects a large crawler platform for an upper level because its local height is suitable. The estimate omits structural load assessment and the machine's delivery/removal route. The selected height has solved only one part of the problem. Establish the support and logistics scope before including that machine in the upper-floor shortlist.
