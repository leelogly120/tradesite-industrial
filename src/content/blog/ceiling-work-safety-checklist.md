# Ceiling Work Safety Checklist: The Complete 50-Point Inspection

I've been doing ceiling work for over a decade. In that time, I've developed a 50-point safety checklist that has prevented every potential incident. Here's the exact checklist I use.

## Why This Checklist Matters

**The cost of skipping safety:**
- 1 fall incident = $100,000-500,000 in costs
- 1 fatality = $1,000,000+ in costs + criminal liability
- 1 serious injury = $50,000-200,000 in costs + lost time

**The cost of this checklist:**
- 5 minutes of inspection time
- $0 in direct costs

**The math is simple.**

## Pre-Work Inspection (Points 1-15)

### Equipment Inspection

- [ ] **1. Platform guardrails secure** — Check all connections
- [ ] **2. Platform floor clean** — No debris, no trip hazards
- [ ] **3. Controls functional** — Test all buttons and joysticks
- [ ] **4. Emergency stop working** — Test from multiple locations
- [ ] **5. Safety devices operational** — Overload, tilt, wind sensors

### Personal Protective Equipment

- [ ] **6. Hard hat condition** — No cracks, proper fit
- [ ] **7. Safety glasses** — Clean, undamaged
- [ ] **8. High-vis vest** — Visible, reflective strips intact
- [ ] **9. Safety boots** — Steel toe, non-slip soles
- [ ] **10. Gloves** — Appropriate for task

### Fall Protection

- [ ] **11. Harness inspection** — Webbing, stitching, hardware
- [ ] **12. Lanyard condition** — No damage, proper length
- [ ] **13. Anchor points verified** — 5,000 kg capacity
- [ ] **14. Rescue equipment ready** — Kit on-site
- [ ] **15. Emergency plan reviewed** — Everyone knows procedures

## Site Assessment (Points 16-25)

### Environmental Conditions

- [ ] **16. Wind speed <10 m/s** — Check forecast and current
- [ ] **17. No lightning expected** — 30-minute rule
- [ ] **18. Visibility adequate** — No fog, heavy rain
- [ ] **19. Temperature acceptable** — -10°C to +40°C
- [ ] **20. Ground conditions stable** — No soft spots

### Work Area

- [ ] **21. Exclusion zone established** — Barriers in place
- [ ] **22. Access routes clear** — Emergency access maintained
- [ ] **23. Overhead hazards identified** — Power lines, structures
- [ ] **24. Floor protection planned** — Mats if needed
- [ ] **25. Material staging area** — Designated, organized

## Tool and Material Safety (Points 26-35)

### Tool Tethering

- [ ] **26. All tools tethered** — No exceptions
- [ ] **27. Tether ratings verified** — Match tool weight
- [ ] **28. Anchor points identified** — For each tool
- [ ] **29. Tool condition checked** — No damage
- [ ] **30. Tool pouches available** — For small items

### Material Handling

- [ ] **31. Load calculations complete** — Platform capacity not exceeded
- [ ] **32. Material secured** — Before lifting
- [ ] **33. Lifting plan reviewed** — For heavy items
- [ ] **34. Drop protection in place** — Netting if needed
- [ ] **35. Material storage designated** — On platform

## Communication and Emergency (Points 36-45)

### Communication Systems

- [ ] **36. Radios tested** — All units working
- [ ] **37. Backup communication** — Phone numbers available
- [ ] **38. Emergency contacts posted** — Visible to all
- [ ] **39. Signal system established** — Hand signals agreed
- [ ] **40. Shift handover procedure** — Documented

### Emergency Preparedness

- [ ] **41. First aid kit accessible** — Stocked and current
- [ ] **42. First aider identified** — Certified, on-site
- [ ] **43. Emergency services number** — Posted, known
- [ ] **44. Evacuation route clear** — Marked, unobstructed
- [ ] **45. Assembly point identified** — Known to all

## Documentation and Final Check (Points 46-50)

### Documentation

- [ ] **46. Pre-work inspection documented** — Form completed
- [ ] **47. Risk assessment reviewed** — Current, approved
- [ ] **48. Training records verified** — All workers certified
- [ ] **49. Equipment maintenance current** — Service records up to date
- [ ] **50. Client notified** — Work starting, area secured

## How to Use This Checklist

### Before Every Shift

1. Print or digital copy available
2. Walk through each point with crew
3. Mark completion
4. Address any failures immediately
5. Document and file

### After Any Incident

1. Review checklist for gaps
2. Update if needed
3. Retrain crew
4. Implement corrective actions

## The 5-Minute Rule

**If any point fails, stop work.**

It takes 5 minutes to check. It takes 5 days to recover from an incident.

**No exceptions. No shortcuts.**
