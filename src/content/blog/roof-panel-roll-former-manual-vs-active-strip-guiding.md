Choose adjustable entry guides when conforming strip stays within the first-pass lateral tolerance and cut panels meet the drawing across representative runs. Add active strip steering when conforming strip still wanders beyond that tolerance after the entry is aligned, and a trial proves the added stage brings the position and panel dimensions into tolerance. First ask the line supplier to mark the first-pass datum on the layout and quote a trial covering the order conditions most likely to expose wander.

The feed bed below shows the width of the entry area. Ask the supplier to mark the feed entry, any proposed sensing point and the first forming pass on the same drawing.

## Set up a fair test at the first pass

Adjustable guides set the incoming strip's position across the line and its height at the first forming pass. Poor alignment can contribute to twist, edge damage and dimensional variation. Ask the line supplier to show its setup reference. If the strip is consistently off-center at one setting, have the supplier investigate that alignment before pricing an upgrade. [Roll-Kraft entry-guide guidance](https://www.roll-kraft.com/technical-resources/entry-guides-where-proper-roll-forming-begins)

Separate variation between setups from movement after a run starts. If the manual guide can be reset to the same reference and the repeated runs pass, include the documented reset in the manual offer. If the strip still wanders while that setting is held, identify where and when the drift starts. Record coil ID, width, incoming camber, the observed operating state and strip position at the relevant reference. Follow that record through to the cut panel's critical measurements. Hold the rest of the entry arrangement fixed during the comparison, including the [decoiler and feed choice](/blog/roof-panel-line-powered-decoiler-vs-pull-through-feed/).

## Price the correction, including the handoff to the guide

Active steering combines a position sensor, controller and actuator. Metal-strip systems can sense an edge or the center. Ask the integrator which feature the proposal tracks, where correction takes place and which mechanical guides the strip still uses to reach the first pass. Include the controller and moving assembly when pricing automatic correction. [EMG metal-strip guiding overview](https://www.emg.elexis.group/solutions/strip-guiding-solutions)

Settle the edge-versus-center question before the trial. An edge-controlled offer holds a nominated side to the agreed reference. If the application is sensitive to variations in width on both sides of center, have the integrator explain how the proposed system establishes the strip center and what width variation remains permissible. Use the actual panel drawing to decide which measurement matters. Ask for a trace from the sensor point and a position check at the first pass so the data covers the point that feeds the rolls.

## What a production-length trial should settle

Include the intended widths and surfaces that challenge the entry arrangement. Ask the supplier to reproduce the relevant steady run and normal start of an order, then associate strip position with actual finished panels. Both offers get the same accepted input condition, downstream tooling and inspection requirements. Give purchasing the cost of the whole installed option, including service and ongoing support. If both qualify, use the trial to identify the manual resets and rejects attributable to strip position. Price their effect with the buyer's order records. Retain the base package when the active option cannot recover its extra cost over the same period.

### Two hypothetical faults in the comparison

**Mistake 1.** A buyer selects active steering after trials on an unusually bowed strip. The supplier's inspection shows that the coil exceeds the purchase camber limit. Hold the coil for a quality decision and compare both offers on identified conforming stock.

**Mistake 2.** A buyer signs off a stable sensor reading before checking the strip at the first pass. At normal running duty, the finished panel still varies in seam width. Require both the downstream position result and the finished-panel measurements in the same trial record.
