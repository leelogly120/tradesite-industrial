Start with a wheeled rough-terrain scissor for repeated short workfaces reached through usable site corridors when its offered deck covers each task. Choose a crawler large-deck proposal for a continuous shared workface that the scissor offer cannot serve as one accepted working area, provided the crawler's complete support footprint is available. When both cover the work, compare complete task cost.

Both alternatives are personnel-access equipment, not a truck-mounted roof-former lift. The purchase changes the working arrangement and site occupation as well as the undercarriage. Neither “rough terrain” nor “crawler” establishes suitability for an unassessed floor or access route.

## Keep the wheeled candidate in the comparison until its actual deck is drawn

Do not compare a broad crawler deck with an imagined tiny scissor platform. [Skyjack's full-size rough-terrain scissor product information](https://www.skyjack.com/en-eu/product/sj9253-rt) includes a defined platform and extension arrangement. Use the actual competing configuration and its instructions, rather than a generic picture of the equipment class.

Draw the people, tool positions and task materials on each offered working surface. Show whether they must work together along one fixing band or can complete separate positions. Include the offered extension configuration and the applicable task limits for each candidate.

The deck-level photograph below shows a broad mesh surface, guardrails and attached equipment. It helps the buyer describe the working arrangement. The quotation must state the actual permitted use and distribution of the crew, tools and materials; a visible auxiliary arm does not supply a handling allowance.

![Two orange booms extend over a red mesh work deck with perimeter guardrails.](/images/equipment/buyer-20261031-deck-top.webp)
*Place the real crew and task materials on each offered deck drawing before claiming a coverage advantage.*

A larger surface has purchasing value when the task uses it. For scattered visits with little shared activity, compare the access needed at each point and the transitions between points. For a coordinated long work band, compare the whole accepted work arrangement, including any additional machine or material-handling resource the competing offer requires.

## Ground acceptance is a separate test for each candidate

Obtain the equipment-side loads and complete support and movement arrangements for both offers. The site engineer assesses them against the actual surface and supporting construction. Tracks spread contact differently from wheels, but the name of the undercarriage does not establish an acceptable support load or remove the effect of deployed legs.

Keep the arrival route separate from the working positions. Turning, passing a doorway and occupying a support area are different geometry checks. A machine that arrives along the site road still needs a usable position beside the installation task.

The [IPAF ground-assessment guidance](https://www.ipaf.org/en/operator-feeds/do-you-know-what-look-when-assessing-ground-conditions) addresses both operating areas and the ground crossed to reach them. Use that complete route in the purchasing comparison. Keep permitted movement states with the actual equipment documents; price the work those documents require.

## A common worksheet for two self-propelled access offers

Use the same building grids and supporting-floor datum for both bidders. Enter dimensions from issued surveys and offered configuration drawings rather than from photographs.

| Buyer field | Project entry and reference | Responsible input owner | Decision use |
| --- | --- | --- | --- |
| Finished task | Work strip or point IDs and required completed output ___ | Installation lead | Holds the work scope constant |
| Shared work surface | Crew positions, material presentation and simultaneous activities ___ | Installer and equipment providers | Tests whether either deck needs an extra access or handling resource |
| Offered configuration | Main deck, extensions, support arrangement and task limits ___ | Each actual equipment provider | Admits only the configuration priced |
| Working positions | Floor-to-task height, lateral offset and surrounding structure ___ | Surveyor and work planner | Maps each candidate to the actual workface |
| Access corridors | Clear route, turns, openings and restrictions ___ | Site logistics planner | Accepts or rejects arrival and relocation paths |
| Supporting surface | Ground/slab records and proposed wheel, track and support reactions ___ | Providers supply loads; site engineer assesses support | Establishes eligible equipment/location combinations |
| Work transitions | Position sequence, replenishment and released occupation windows ___ | Installation supervisor | Completes the task programme for both offers |
| Total package | Equipment, transport, site preparation, support services and removal ___ | Estimator using actual quotations | Ranks eligible packages over the same output |

Record different site phases when their conditions change. An open construction area and a finished floor with operating equipment are not the same working environment. Buy for the phases the equipment must actually serve.

## Separate a ground problem from a workface problem

The unfinished hall below contains debris and an irregular surface along the approach to distant access equipment. It illustrates the need for a surveyed route and an accepted ground arrangement. It does not identify either candidate as suitable for that surface.

![An unfinished industrial hall has debris and uneven ground along a route toward a distant red platform.](/images/equipment/buyer-20261102-hall-ground-route.webp)
*Survey the approach and working areas in their real construction condition before pricing either access package.*

If the site's engineering review excludes both offers from a required location, change the access package or price an accepted supporting arrangement. Do not buy tracks to avoid obtaining the supporting data. If both candidates are accepted on the route, return to their task coverage and complete cost.

Likewise, ground preparation cannot fix an unsuitable working surface. A scissor candidate that covers the task with its actual deck remains in the shortlist. One that leaves a required simultaneous position uncovered needs an explicit additional resource. Apply exactly the same rule to the crawler proposal.

This comparison is different from deciding whether to pay for elevated travel. The [relocation-duty guide](/blog/ceiling-platform-elevated-travel-vs-repositioning/) addresses that feature within an offered configuration. Here the buyer compares two complete equipment architectures for the task and site.

## Two equipment-class assumptions that fail

**Mistake: a crawler is bought as the ground solution.** A hypothetical estimator removes ground preparation from the budget because the selected machine has tracks. The offered working arrangement also uses support legs, and its actual reactions have not been assessed against the floor. Restore the equipment-specific support review and price its accepted site arrangement before choosing the machine.

**Mistake: the competing scissor is rejected from a small-platform photograph.** Another buyer pays for a larger machine without drawing the actual full-size scissor offer or its permitted extension arrangement. The priced alternative already covers the required crew positions. Compare the real drawings and complete task resources before paying for a coverage advantage the work does not use.

Both examples replace a category shortcut with an equipment-and-task comparison. No generic undercarriage provides a universal cost, ground-pressure or productivity advantage.
