**Choose a modular container route when the equipment has an approved separation plan and the destination can perform the required assembly and checks. Compare a more assembled special-cargo route when destination integration is the weak link and the entire transport chain can accept that cargo.** Select the route by its complete cost and readiness at destination, rather than the ocean freight line alone.

Compare the arrival condition stated in each container or out-of-gauge proposal. One can leave major assemblies to connect; the other can preserve more connections while creating a larger transport envelope. The useful buying question is what each route requires before the same agreed commissioning stage.

## First decide what you need to arrive

Describe the desired destination condition in plain terms. Specify separate lift and forming modules when an equipped integration workshop will complete them; request a more assembled package when local resources cannot perform the proposed reconnection work. Identify whether the truck chassis is included, supplied locally or outside the present order.

These are supply choices, not merely different container bookings. A locally supplied chassis introduces a local integration task. Credit a more assembled shipment only for the reconnection tasks it actually removes; retain the remaining inspection, commissioning and destination work in the offer.

Its name opens that review; the actual module dimensions, masses and handling arrangement determine whether the proposed container route works. ## Special cargo is a route to investigate, not a single box

[Maersk's special-cargo guidance](https://www.maersk.com/industry-sectors/special-cargo) distinguishes in-gauge cargo, out-of-gauge cargo that exceeds a flat rack or open top's dimensions, and breakbulk. The carrier's classification and acceptance depend on the actual cargo. A large machine is not automatically assigned the same equipment or handling method as another large machine.

Ask the forwarder or carrier to evaluate the issued transport package, including its support and securing basis. If it proposes a different split, return that proposal to the equipment supplier before treating it as an equivalent route. Transport convenience should not create an unreviewed machine disassembly.

Keep both options alive until they reach comparable definition. A container budget without an approved module breakdown is incomplete. So is a special-cargo price without terminal handling and the destination inland leg.

## Compare both routes to the same destination milestone

The table below ends at the same agreed commissioning-ready condition. Enter named providers and quoted amounts, and reject a route that leaves essential destination work without a provider.

| Cost or dependency | Modular container route | More assembled special-cargo route | Buyer entry |
| --- | --- | --- | --- |
| Origin preparation | Approved separation, protection and packing | Approved transport condition and securing preparation | Equipment supplier: issues separated/assembled transport drawings and origin preparation price |
| Ocean and terminal work | Accepted packages and container arrangement | Accepted cargo classification and handling arrangement | Forwarder: returns carrier-accepted package classification and ocean/terminal quote |
| Inland transport | All modules reach the assembly location | Larger cargo reaches the receiving location | Destination carrier: enters packed envelope, measured route constraints and unloading scope |
| Local resources | Assembly area, equipment, people and stated checks | Resources for remaining completion and checks | Receiving manager: names assembly staff, equipment, work area and booked dates |
| Chassis integration | Required if the offered scope uses a local vehicle | Required according to the actual supplied condition | Chassis integrator: supplies vehicle/interface proposal and integration quotation where required |
| Time dependencies | Module arrivals and assembly readiness | Accepted transport service and receiving readiness | Planner: records provider-supported arrival/completion dates to test project readiness |
| Final comparison point | Agreed commissioning-ready configuration | The same configuration and milestone | Buyer: identifies each remaining task and its provider at the same commissioning-ready milestone |

The lowest total is meaningful only if both columns describe feasible routes. An unpriced assembly task is not a saving. Equally, a higher ocean quotation buys little value if the proposed cargo still requires the same destination work as the container option.

## When paying for a larger transport envelope makes sense

Consider a buyer with a suitable receiving workshop but no team for the proposed structural, hydraulic or electrical reconnection work. If a more assembled configuration removes specific tasks and the carrier accepts the whole route, the extra transport cost deserves comparison with a qualified local service quotation and the associated schedule.

Be precise about which tasks disappear. Ask the supplier for the arrival condition under each option and a list of work remaining. If both routes require the same local chassis integration, do not credit the special-cargo route with eliminating it.

Choose approved modules when the importer has an integration workshop equipped and staffed for the specified assembly tasks. Its existing resources can make destination assembly a planned part of delivery. Count the real use of those resources, including any work displaced, rather than treating an owned workshop as free.

This is a repeatable business choice. For an importer planning several future orders, repeat the comparison once named local staff and facilities can perform the required integration work. For a first one-off purchase, choose using the resources available for this order.

## Two apparent freight savings that disappear

**Failure case: the container arrives before the integration capability exists.** A buyer accepts a low ocean quotation while planning to find an assembly provider later. The modules arrive, but the required people, equipment and applicable instructions have not been coordinated. Price and schedule the destination work before choosing the modular route.

**Failure case: the large package has an ocean route but no inland route.** A buyer pays to preserve more of the machine's assembled condition, then discovers that the proposed receiving route or unloading arrangement has not been assessed for that cargo. Return to the complete transport proposal before booking; ocean acceptance alone is not an arrival plan.
